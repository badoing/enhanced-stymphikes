# Enhanced Stymphikes

A RuneLite plugin for Stymphike hunting in Vampyrium. It highlights each step of the hunting cycle so you always know what to click next.

## How it works

1. **Ready to bait** – Stymphike trees are highlighted green.
2. **Tree baited** – once the bait is in, the tree's highlight is removed and the hiding bushes are highlighted green.
3. **Hidden in a bush** – all highlights are hidden, the screen darkens and a 38 second countdown is shown over the baited tree. Press Esc (configurable) to close the dark screen early.
4. **Stymphike speared** – the screen returns to normal and the tree is highlighted green again, ready for the next cycle.

### Leaving the bush

If you step out of the bush before the Stymphike is speared, a warning pops up and the countdown keeps running:

- **Re-enter the bush** and it will still be speared automatically on your next rustle. A green "Auto-spear in Xs" countdown shows when that will happen.
- **Stay out** and a red "Spear now!" prompt appears when it lands – it flies off after about 3 seconds unless you spear it manually.

### Other features

- Stats box in the top left: Stymphikes speared, speared per hour, Hunter XP gained and XP per hour.
- Optional red screen flash for a few seconds after you take a hit while Stymphike hunting.

## Settings

- Tree and bush highlight colours, fill opacity, outline width
- Tile outline and/or 3D hull highlighting
- Optional flashing highlights
- Hiding timer on/off and timer size
- Darken screen on/off, darkness amount, keep chat box bright, close-dark-screen key
- Stats box on/off
- Left-bush warning on/off
- Red flash when hit on/off
